2. HOW "SETTLED" WAS DECIDED
----------------------------
Each tab_ex2_q{1,2,3}_provenance.csv records the sha256 of every run file
its tables were built from. Those hashes were recomputed against the
working tree at snapshot time. A cell is settled when its hash still
matches, which means no row has landed since the table was built. Every
cell in section 1 matched, hash for hash.
